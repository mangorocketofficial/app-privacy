이 방침은 전기기능사 회로 학습을 위한 「전기기능사 실기 연습」 Android 앱에 적용됩니다.

현재 0.7.1 준비 버전에는 광고·분석 SDK가 연결되어 있지 않습니다. 광고 서비스를 도입하는 버전을 배포하기 전에 데이터 처리 항목, 제공업체, 동의 방법과 본 방침을 갱신합니다.

1. 기기에 저장하는 정보와 이용 목적

앱은 배선·부품 배치, 이름을 붙인 저장본, 문제별 진행 상태, 모의시험 도전 횟수와 시간·결과, 취약 항목, 테마·안내 설정을 기기에 저장합니다. 이 정보는 실습 이어하기, 결과 확인, 복습과 설정 유지에 사용합니다. 현재 앱은 이 기록을 운영자의 서버로 전송하지 않으며, 별도의 회원가입·로그인·클라우드 동기화 기능을 제공하지 않습니다.

기능상 연락처, 사진, 전화번호, 정밀 위치, 마이크 또는 카메라 접근을 요구하지 않습니다. 저장본 이름에는 민감한 개인정보를 입력하지 않는 것이 좋습니다. 운영체제 및 이용자의 백업 설정에 따라 앱 데이터가 백업될 수 있습니다.

2. 광고와 분석

현재 버전에는 실제 광고 요청과 외부 이용 분석 기능이 없습니다. 광고 흐름의 디자인 미리보기는 실제 광고 송출이나 광고 식별자 수집을 수행하지 않습니다. 앞으로 광고 SDK를 도입할 경우 실제 처리 내용에 맞춰 이 방침을 수정하고, 필요한 동의와 개인정보 선택 기능을 제공한 뒤 해당 버전을 배포합니다.

3. 외부 링크와 이 페이지의 호스팅

앱에서 Q-Net 원문 등의 외부 링크를 선택하면 해당 서비스에 접속합니다. 외부 서비스의 데이터 처리는 그 서비스의 개인정보처리방침을 따릅니다. 이 방침 페이지는 GitHub Pages에서 제공되며, 페이지 방문 시 GitHub가 서비스 운영과 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. 이 페이지에는 자체 분석 도구나 광고 스크립트가 없습니다. GitHub 개인정보처리방침을 참고하세요.

4. 문의 처리와 제3자 제공

이메일 문의 시 회신 주소와 이용자가 보낸 내용을 문의 응대와 문제 해결 목적으로 처리합니다. 문의 처리에 불필요한 개인정보는 보내지 마세요. 현재 앱은 기기 내 학습 기록을 운영자 또는 광고업체에게 전송하지 않습니다. 이메일 서비스 및 외부 링크 서비스가 자체적으로 처리하는 정보는 각 제공자의 정책을 따릅니다.

5. 보관과 삭제, 이용자 권리

기기 내 정보는 앱의 해당 기록 삭제 기능 또는 Android 설정의 앱 데이터 삭제 기능으로 삭제할 수 있습니다. 앱을 삭제하면 기기 내 기록을 잃을 수 있으며 운영체제 백업에 남은 정보는 해당 백업 설정에서 관리해야 합니다. 운영자는 기기 내 학습 기록의 서버 사본을 보관하지 않아 이를 대신 복구하거나 원격 삭제할 수 없습니다.

문의로 받은 정보는 문의 해결에 필요한 동안 처리하고, 처리가 끝나면 법령상 보관이 필요한 경우를 제외하고 불필요한 정보를 삭제합니다. 운영자가 처리하는 문의 정보의 열람·정정·삭제·처리 제한은 위 이메일로 요청할 수 있습니다.

6. 정보 보호

앱은 운영체제가 제공하는 앱 저장 공간을 사용합니다. 기기를 다른 사람과 공유할 때 기기 잠금 등 보호 설정을 사용하세요. 운영자는 기능과 데이터 처리 방식의 변경 시 접근 범위와 보관 필요성을 검토합니다.

7. 방침 변경

앱 기능 또는 데이터 처리 방식이 변경되면 이 페이지와 시행일을 갱신하고 필요한 방식으로 변경 내용을 안내합니다. 특히 광고 SDK가 포함되는 버전의 출시 전에 관련 데이터 처리 내용을 반영합니다.
